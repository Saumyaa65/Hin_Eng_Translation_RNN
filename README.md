# Hindi-English Translation RNN

This project focuses on **neural machine translation**, specifically building a system to translate sentences from English to Hindi. It leverages **Recurrent Neural Networks (RNNs)**, with **Long Short-Term Memory (LSTM) units**, to achieve this task.

## Overview

The core of this translation system is a classic **Encoder-Decoder architecture**:
* **Encoder:** This part processes the input English sentence. Its role is to understand the sentence's meaning and compress it into a numerical "thought vector" or "context."
* **Decoder:** This part then takes the context generated by the encoder and uses it to generate the corresponding Hindi translation, character by character.

The model operates at the **character level**, meaning it learns translations by processing individual characters rather than whole words. This approach helps the model handle new or unseen words more robustly.

## Features

* **Character-level Sequence-to-Sequence (Seq2Seq) Model:** Translates by mapping input character sequences to output character sequences.
* **LSTM-based RNNs:** Utilizes LSTMs, which are well-suited for processing sequential data like language due to their ability to learn and remember long-term dependencies.
* **Standard Encoder-Decoder Framework:** Implements the widely used and effective architecture for machine translation and other sequence generation tasks.

## How It Works

The project follows a typical machine translation workflow:

1.  **Data Loading and Preparation:** English and Hindi sentence pairs are read from text files. All unique characters from both languages are identified and assigned a numerical index.
2.  **Data Vectorization:** The sentences are then transformed into a numerical format (one-hot encoded) that the neural network can process. This involves creating input sequences for the encoder, and input/target sequences for the decoder.
3.  **Model Training:** The Encoder-Decoder LSTM model is constructed and trained. During training, the model learns to predict the next character in the Hindi output sequence based on the current input and the previous context.
4.  **Inference (Translation):** After the model is trained, separate encoder and decoder models are created specifically for translation. To translate a new English sentence, the encoder first processes it to get its internal "state." The decoder then uses this state, predicting one Hindi character at a time, feeding its own output back as input until a complete translated sentence is generated.
